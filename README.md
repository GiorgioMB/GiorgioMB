# Giorgio Micaletto

PhD student in Statistics at the University of Chicago. Website: [giorgiomb.github.io](https://giorgiomb.github.io/).

My work is on results that can be checked rather than trusted: exact graph curvature from one minimum cut, bounds that certify it without solving transport problems, and diagnostics for when a Monte Carlo error estimate can be believed. Outside research I lift heavy things.

## Papers and code

**The Min-Cut Formulation of Ollivier–Ricci Curvature** ([arXiv:2611.32528](https://arxiv.org/abs/2611.32528)). The code is in [orcut](https://github.com/GiorgioMB/orcut), and the solver on its own is the Python package [faster-or-curvature](https://pypi.org/project/faster-or-curvature/) ([source](https://github.com/GiorgioMB/faster-or-curvature)). There is an [interactive demo](https://giorgiomb.github.io/projects/min-cut/).

**From Proxy to Certificate: Two-Sided Ollivier–Ricci Bounds from Balanced Forman Curvature**, with Tebe Nigrelli ([arXiv:2603.13535](https://arxiv.org/abs/2603.13535)). The experiments are in [Curvature-Transfer-Code](https://github.com/GiorgioMB/Curvature-Transfer-Code) and the Lean proof in [BF-OR-Lean](https://github.com/GiorgioMB/BF-OR-Lean).

**Bridge Sampling Diagnostics**, with Aki Vehtari ([arXiv:2508.14487](https://arxiv.org/abs/2508.14487)). The code is in [bridgesampling_paper_code](https://github.com/GiorgioMB/bridgesampling_paper_code) and [bridgesamplingparetok](https://github.com/GiorgioMB/bridgesamplingparetok). The Monte Carlo standard error and a CmdStanR method are merged into the [bridgesampling](https://github.com/quentingronau/bridgesampling) R package.

Coursework and smaller projects are in [UndergradProjects](https://github.com/GiorgioMB/UndergradProjects) and [GradProjects](https://github.com/GiorgioMB/GradProjects).
